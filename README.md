Vuejs

Pour lancer le projet partie front :

Ouvrir un un terminale dans le projet, ensuite :
- npm install
- npm run serve
- ouvrir le port http://localhost:8081/



NodeJs

Pour lancer la partie backend du projet :
	Ouvrir un terminale dans le kanban\backend_node :
- npm install
- npm start

Mongo
- Installer d’abord le serveur mongodb
- Ensuite lancer dans le port localhost:27017
- Et enfin créer un base de donnée avec le nom « kanban »
